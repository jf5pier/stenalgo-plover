# stenalgo-plover

Plover plugins for [Stenalgo](https://github.com/jf5pier/stenalgo)'s French Starboard steno theory.

- **System** `Stenalgo French` (`plover_stenalgo/system.py`, key table `_generated_keys.py`).
- **Dictionary** `.stenalgo` (`plover_stenalgo/dictionary.py`): decodes the expression abbreviations (`il n'`, `de la`, ...).
  It reads two files placed side by side, both generated by the Stenalgo repository and NOT part of this package:
  `plover_stenalgo_expressions.stenalgo` and `plover_stenalgo_dictionary.json` (add the `.stenalgo` file above the JSON
  in Plover's dictionary list of the Stenalgo system). A fingerprint refuses a JSON built from another theory.

Requires Python >= 3.12 (Plover 5.4 ships 3.13).

Install (Plover's plugins folder, Windows): `plover_plugins install git+https://github.com/jf5pier/stenalgo-plover`
(or `python.exe -m plover.plugins_manager install <path>` with `PYTHONUSERBASE` set to `<plover config>\plugins\win`),
then restart Plover.

`plover_stenalgo/_core/` is generated from the Stenalgo repository (`python -m util.export_plover_plugin`): do not edit it here.
This repository is hand-synced from `plover_stenalgo/` of the Stenalgo repository.
