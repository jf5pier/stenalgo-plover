# stenalgo-plover

Plover plugins for [Stenalgo](https://github.com/jf5pier/stenalgo)'s French Starboard steno theory.

- **System** `Stenalgo French` (`plover_stenalgo/system.py`, key table `_generated_keys.py`).
- **Dictionary** `.stenalgo` (`plover_stenalgo/dictionary.py`): decodes the expression abbreviations (`il n'`, `de la`, ...).
  It reads two data files generated by the Stenalgo repository, which ship in this package under
  `plover_stenalgo/dictionaries/`: `plover_stenalgo_expressions.stenalgo` and `plover_stenalgo_dictionary.json`, side by
  side (the word index is read from the JSON; a fingerprint refuses a pair built from different theories). The system
  lists them in its default dictionaries, expressions above the stock JSON. Plover applies defaults only to a config
  with no dictionary list of its own for the Stenalgo system: an older `plover.cfg` keeps its list until it is removed.

Requires Python >= 3.12 (Plover 5.4 ships 3.13).

Install (Plover's plugins folder, Windows): `plover_plugins install git+https://github.com/jf5pier/stenalgo-plover`
(or `python.exe -m plover.plugins_manager install <path>` with `PYTHONUSERBASE` set to `<plover config>\plugins\win`),
then restart Plover.

`plover_stenalgo/_core/` is generated from the Stenalgo repository (`python -m util.export_plover_plugin`): do not edit it here.
This repository is synced from `plover_stenalgo/` of the Stenalgo repository by `python -m util.sync_plover_mirror <clone>`,
which also stores the generated `dictionaries/` here (they are gitignored in the Stenalgo repository). Do not edit it by hand.
